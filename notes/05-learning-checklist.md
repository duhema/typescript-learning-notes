# 05 · DOM 引导练习与自测

把元素创建、坐标、步骤状态和鼠标区域放在一起观察，可以检验这些知识是否真正连起来。练习记录留空，按实际运行结果填写。

## 观察一条完整流程

完成前四节的练习后，可以用开始说明、四个目标区域和结束说明检验整个流程。引导直接使用练习页面中已有的区域与控件。

| 操作 | 预期现象 | 观察记录 |
| --- | --- | --- |
| 打开页面 | 开始说明出现在固定屏幕位置，背景变灰 | 待填写 |
| 滚动页面 | 开始说明的屏幕位置不变 | 待填写 |
| 点击次へ | 对应目标进入视口，旁边出现说明 | 待填写 |
| 点击目标内控件 | 原有操作生效 | 待填写 |
| 点击灰色区域内按钮 | 鼠标操作被遮罩挡住 | 待填写 |
| 手动上下滚动 | 提示与目标一起移动，定位用的 CSS top 不改变 | 待填写 |
| 继续切换目标 | 文案、位置和四块遮罩在切步时更新 | 待填写 |
| 到达最后一条 | 回到固定位置说明，按钮显示終了 | 待填写 |
| 点击終了或关闭 | 弹窗和遮罩移除，页面恢复鼠标操作 | 待填写 |

绝对定位与整页滚动配合的条件是：定位参照与文档坐标一致，目标在当前步骤中没有发生布局位移。只改滚动距离时无需重新测量；布局变化时则应在相应操作完成后重新布局。

## 常见现象与检查方向

| 现象 | 检查方向 |
| --- | --- |
| 提示偏移一个页面滚动距离 | absolute 是否使用了 rect + scroll；fixed 是否误加了 scroll |
| 初始显示就发生变量错误 | currentStep 是否在 showStep(0) 之前初始化 |
| querySelector 的参数报类型错误 | string|null 是否先区分 null |
| 名字相似的变量报“找不到” | 实际声明的是 left，还是 absoluteLeft；作用域是否正确 |
| 文字切换了，位置没换 | 是否在更新文案后调用 positionPopup |
| 目标清晰但不能点 | SVG 根或透明图形是否仍在接收鼠标 |
| 灰色有更深的交叠条纹 | 四块矩形是否重复覆盖了相同区域 |
| 每点击一次跳了多步 | 是否在显示函数内反复注册新的点击回调 |
| 结束后页面仍有遮挡 | 是否同时移除 mask 与 popup |
| 窗口变窄后位置不再贴合 | 窗口变化导致布局重排，需在适当时机重新布局 |

这些判断要结合浏览器中的实际 DOM 与计算样式。没有证据时，不先用类型断言或增大 z-index 掩盖问题。

## 练习一：坐标换算

目标视口 bottom=310，scrollY=420，gap=16。提示使用 absolute，top 应是多少？整页继续向下滚动 90 后，它的 CSS top 应该改变吗？

<details>
<summary>参考答案</summary>

top=310+420+16=746px。普通滚动后，目标视口 bottom 变成 220，scrollY 变成 510，相加结果仍是 730；提示的 CSS top 仍为 746px，无需再次赋值。

</details>

## 练习二：六项数组的边界

当前 index=4，steps.length=6。点击一次后显示哪一项？按钮文字应是什么？再点击一次会发生什么？

<details>
<summary>参考答案</summary>

先显示索引 5，它是最后一项，按钮应显示終了。再点击进入 index=6，达到 steps.length，执行 finish，不读取 steps[6]。

</details>

## 练习三：调整间距

在练习副本中把 gap 从 12 改为 20，先预测再运行：

- 方向不变时，目标与提示的距离如何变化？
- 在空间紧张的情况下，是否可能改变摆放方向？
- 为什么需要重新进入步骤，才能看到新的位置？

<details>
<summary>参考答案</summary>

间距增大 8px；空间判断也使用 gap，所以可能切换到上方或左侧。坐标在进入步骤时计算，修改数值不会自动重新执行函数，需要重新显示步骤或刷新练习页面。

</details>

## 练习四：为遮罩算尺寸

文档宽 900、高 1800；目标 left=80、top=500、width=320、height=140。写出右侧与下方矩形的坐标和宽高。

<details>
<summary>参考答案</summary>

right=400、bottom=640。右侧矩形为 x=400、y=500、width=500、height=140；下方矩形为 x=0、y=640、width=900、height=1160。

</details>

## 知识检查

- [ ] 能区分 DOM 类型与真实对象。
- [ ] 能解释为什么有效的字符串不一定是有效的 CSS 值。
- [ ] 能判断一个变量是新节点还是原节点的另一个引用。
- [ ] 能将视口坐标转换成文档坐标。
- [ ] 能解释普通滚动与布局变化的区别。
- [ ] 能用数组与下标描述下一步和结束。
- [ ] 能区分没有目标与目标没找到。
- [ ] 能解释四块 SVG 的尺寸与鼠标接收范围。

本练习处理鼠标遮挡；键盘焦点管理是另外一个主题。页面内部滚动容器、动态重排等，也需要结合各自的定位关系处理，不把一个练习当成所有网页的通用组件。
